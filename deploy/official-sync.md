# 成绩同步设置

本功能默认关闭，支持更新个人成绩并上传已绑定的水鱼和落雪，PC 数据保存在本地。

## 管理员设置

1. 在运行 AstrBot 的同一 Python 环境安装本插件 `requirements.txt`。
2. 在「官方成绩同步」组开启功能，高级连接参数通常保持默认。
3. 水鱼应用需有 `prober.records.write` 权限，落雪应用需有 `write_player` 权限。已有绑定缺少写入权限时，用户需重新绑定并确认授权。
4. 配置完成后重载插件。请勿在机台游玩期间使用同步功能。

Windows 下已验证个人成绩及 PC 数据获取；Linux/ARM64 部署及查分器实际上传仍待验证。

## 用户操作

发送「导」「更新b50」或「更新乐曲数据」，按提示在同一会话180秒内发送自己的 SGID 字符串、官方玩家二维码链接或单张二维码图片。也支持「同步成绩」「更新成绩」。

可以直接发送「更新b50 SGID」或「更新b50 官方二维码链接」，将占位内容替换为实际凭据；「导」「更新乐曲数据」也支持相同用法。仅群聊尝试撤回凭据消息，失败提醒手动撤回，私聊不撤回、不提示撤回。

处理完成会反馈各查分器结果，仅上传成功时显示该平台上传的成绩条数。上传失败可发送「重传成绩」；发送「pc50」查看本地常玩谱面，或发送「删除PC数据」删除自己的本地快照。

常见交互文案见 [成绩同步使用流程](official-sync-flow.md)。

## 冷却与每日次数

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `official_fetch_cooldown` | 300秒 | 每人取数冷却 |
| `official_fetch_daily_limit` | 10次 | 每人每日取数上限 |
| `official_upload_cooldown` | 60秒 | 每人上传冷却，自动上传和重传共用 |
| `official_upload_daily_limit` | 20次 | 每人每日上传上限 |

每项设0可关闭对应限制。同一平台、机器人和发送者跨群及私聊共用额度，重启保留；每日北京时间00:00重置每日次数，冷却不因跨日提前解除。开始尝试后失败也计次；一次上传水鱼和落雪合计只记一次，未绑定或无可上传成绩不扣上传次数。

上传受限时仍保留已获取的本地成绩，可稍后发送「重传成绩」。删除PC数据、换凭据或重启不会清除限流记录。

## 隐私与故障处理

- 首次成功获取有效成绩后，游戏账号与当前 QQ 建立一对一绑定；账号不符或已绑定其他 QQ 时阻止保存和上传。更换账号需管理员在玩家管理中解绑，同步或重传期间不能解绑，解绑后旧快照不能直接重传。
- 该绑定不能核验首次提交凭据的真实归属，请仅使用自己的凭据，不要转发他人的字符串、链接或二维码。
- 插件不保存二维码原图或原始登录凭据；AstrBot 核心及消息平台可能自行保留消息日志和图片缓存，撤回不能清除已有记录。
- 图片不超过12 MB及1600万像素，识别失败可在等待期限内重发。
- 获取成绩失败不覆盖旧快照；上传失败不删除已保存成绩，一边失败不影响另一边处理。
- 连接或授权异常时请获取新凭据、检查依赖与网络，必要时联系管理员。不要关闭安全校验。
- 限流记录读写失败时停止相关请求，管理员应检查持久化目录权限及文件状态。
