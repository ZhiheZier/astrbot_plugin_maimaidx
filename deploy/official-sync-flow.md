# 成绩同步使用流程与回复示例

本文记录用户操作流程及常见回复，便于逐条讨论。示例中的 N 为运行时替换值。

## 1. 总线路

```text
导 / 更新b50 / 更新乐曲数据（兼容同步成绩、更新成绩）
  → 检查本群舞萌功能、官方同步配置及取数额度（只检查不扣次）
  → 提示在本会话180秒内发送凭据
  → 接收 SGID 字符串、官方玩家二维码链接或单张二维码图片
  → 图片：读取到内存 → 仅群聊尝试撤回 → 识别二维码
     文本/官方链接：仅群聊尝试撤回 → 本地解析凭据
  → 群聊撤回失败则提醒手动撤回，不因此阻断同步；私聊不撤回、不提示
  → 检查凭据及冷却、次数限制
  → 获取个人成绩 → 保存本地成绩及PC快照
  → 检查上传额度，在首次实际提交前预留 → 上传水鱼及落雪
  → 发送本地保存结果、各平台上传结果及后续命令提示
```

水鱼和落雪分别判断实际 OAuth 绑定，不由查询数据源选项决定。一边失败不影响另一边。官方取数或本地保存失败则不执行后续上传；官方取数或字段校验失败不覆盖旧快照。

数量只在某个查分器的全部批次上传成功后显示，两个查分器分别统计、不合并。它表示成功提交的成绩条数，不等于新增、提升或查分器实际变动的条数。PC 数据保留在本地，同步结果不显示谱面数和 PC 合计；主动发送「我的pc数」仍可查看原有统计。

## 2. 触发与提示

支持「导」「更新b50」「更新乐曲数据」「同步成绩」「更新成绩」，可加 `/` 前缀，b50 不区分大小写。

单独发送命令时，回复一条：

```text
请在 180 秒内于本会话发送完整 SGID 字符串、官方玩家二维码链接，或玩家二维码图片。
仅同步你自己的账号，请先退出机台。SGID 属于敏感登录凭据，请勿转发给他人；也可发送「更新b50 SGID/官方二维码链接」。
首次成功更新绑定当前 QQ，换号需管理员在玩家管理中解绑。
发送「取消成绩更新」可取消。
```

也可「更新b50 SGWCMAID...」「更新b50 <官方玩家二维码链接>」或指令附带一张二维码图片，跳过等待提示，直接处理。请使用自己最新的凭据，过期后需重新获取。

会话按平台、机器人、用户及群聊隔离；不能在其他群或私聊接续提交。本群关闭舞萌功能时静默忽略，不发送提示、不处理凭据。

## 3. 收到凭据

二维码图片先回复：

```text
已收到二维码图片，正在读取，请稍候。
```

文本及官方链接没有上述图片读取提示。仅在 OneBot 群聊尝试撤回凭据消息，撤回成功不单独发送“撤回成功”；私聊不撤回，也不发送撤回提醒。实际群聊入口撤回失败或平台不支持时回复：

```text
消息可能包含登录凭据，自动撤回未成功，请及时手动撤回。
```

内部直接调用文本同步处理函数时使用的同义兜底提示为：

```text
消息包含登录凭据，自动撤回未成功，请及时手动撤回。
```

图片读取、识别成功，或收到文本后，开始取数前回复：

```text
正在获取官方成绩并上传已绑定的查分器，请勿同时登录机台。
```

图片识别过程中，群聊会尝试撤回，私聊跳过撤回。插件不保存二维码原图；核心或平台自身可能留存消息日志或图片缓存，撤回不代表清除这些记录。

## 4. 最终结果消息

取数、校验和本地保存成功后，最终结果为一条消息，格式如下；中间替换为各平台实际结果，尾部固定保留。

```text
官方成绩已获取并保存到本地。
水鱼：上传成功，共上传 N 条成绩。
落雪：上传成功，共上传 N 条成绩。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

### 一边成功、一边失败

```text
官方成绩已获取并保存到本地。
水鱼：上传成功，共上传 N 条成绩。
落雪：上传失败；请检查网络及 write_player 权限，必要时重新「绑定落雪」。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

### 两边失败

```text
官方成绩已获取并保存到本地。
水鱼：上传失败；请检查网络及 prober.records.write 权限，必要时重新「绑定水鱼」。
落雪：上传失败；请检查网络及 write_player 权限，必要时重新「绑定落雪」。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

失败不报告成绩条数。如果前面的批次已成功、后续批次失败，对应平台的失败行改为：

```text
水鱼：上传失败；部分成绩可能已上传，可发送「重传成绩」重试；请检查网络及 prober.records.write 权限，必要时重新「绑定水鱼」。
落雪：上传失败；部分成绩可能已上传，可发送「重传成绩」重试；请检查网络及 write_player 权限，必要时重新「绑定落雪」。
```

### 未绑定或未配置

未绑定时合并为一条绑定提醒，不显示上传条数。两边均未绑定：

```text
请发送「绑定水鱼」或「绑定落雪」完成绑定。
```

只有一个查分器未绑定时，仅提示「请发送『绑定水鱼』完成绑定。」或「请发送『绑定落雪』完成绑定。」，已绑定平台仍正常上传并反馈结果。仅按 QQ 查询的落雪开发者模式不执行 OAuth 上传。管理员未配置水鱼 OAuth 时仍提示「水鱼：未配置 OAuth，已跳过。」，不将配置缺失误报为用户未绑定。

两边均未绑定时仍回复本地保存结果及后续命令提示，不冒称上传成功。目前不会在取数前强制要求绑定查分器，未绑定用户仍可保存本地 PC 数据。

### 部分或全部成绩无法匹配曲库

部分可上传：仅显示各平台结果，不额外追加曲库跳过提示；成功条数按实际上传记录计算，原始 PC 数据仍保留，最后保留固定尾部。

全部无法匹配：不进行任何查分器上传，最终消息为：

```text
官方成绩已获取并保存到本地。
曲库未匹配到可上传的谱面，请先更新曲库；PC 数据仍已保留。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

## 5. 提交、识别与等待失败文案

以下每行均是一条完整回复；按实际故障选择，不会全部发送。

| 场景 | 实际回复 |
| --- | --- |
| 同时提交多张图片，或文本凭据混合图片 | 请一次只发送一个 SGID 字符串或一张玩家二维码图片，不要混合发送。 |
| 图片下载失败 | 二维码图片下载失败，请重新发送原图或 SGID 字符串。 |
| 图片读取失败 | 读取二维码图片失败，请重新发送图片或完整 SGID 字符串。 |
| 图片来源不支持 | 不支持该二维码图片来源，请重新发送图片。 |
| 超过12 MB | 二维码图片过大，请压缩至 12 MB 内后重发。 |
| 超过1600万像素 | 二维码图片像素过大，请裁剪为二维码区域后重发。 |
| 图片损坏或识别异常 | 二维码图片无法识别，请发送清晰的静态二维码图片或完整 SGID 字符串。 |
| 没有有效玩家二维码 | 未识别到有效的玩家二维码，请发送清晰的二维码原图或完整 SGID 字符串。 |
| 一张图包含多个不同玩家二维码 | 检测到多个不同的玩家二维码，请只发送你自己的一个二维码。 |
| 缺少识别依赖 | 缺少二维码识别依赖，请管理员安装 requirements.txt；也可直接发送 SGID 字符串。 |
| SGID格式错误 | SGID 格式不正确，请提供官方公众号中的完整 SGWCMAID 文本。 |
| SGID时间戳非法 | SGID 时间戳无效，请重新获取。 |
| SGID过期或时间异常 | SGID 超出本地三分钟安全窗口，或服务器时间不正确，请重新获取。 |
| 凭据已尝试过 | 此 SGID 已经尝试使用，请重新获取；重传查分器可使用「重传成绩」。 |
| 正在读取/处理另一条凭据 | 正在处理你的成绩凭据，请勿重复发送。 |
| 正在同步成绩 | 你的成绩正在同步，请勿重复提交。 |
| 图片读取期间等待取消、到期或被新的等待替换 | 本次等待已取消或过期，请重新发送「更新b50」后再提交新的凭据。 |

图片读取或识别失败、SGID格式或时间校验失败时，原等待仍在期限内可重发。开始尝试官方请求后，等待会被移除，SGID被标记已尝试；失败后重新触发命令并提交新凭据。

等待自然超时目前不主动发送超时消息；超时后才发来的凭据或其他会话发来的凭据会被静默忽略，也不会尝试撤回。等待中的无关普通文字同样静默忽略。二维码读取途中才到期则有上表的到期提示。

## 6. 配置与同步失败

以下错误会终止本次处理；不会继续上传，也不会发送本地保存成功的结果。已收到凭据且开始处理时，前面的撤回提醒和进度消息可能已经发出。

| 场景 | 实际回复 |
| --- | --- |
| 功能未开启 | 官方成绩同步尚未开启，请联系管理员配置「官方成绩同步」。 |
| 游戏服务拒绝请求 | 官方服务器拒绝了请求，请退出机台后使用新的 SGID 重试。 |
| 正在机台游戏中 | 官方账号当前正在游戏中，请退出机台后重新同步。 |
| 未返回有效成绩 | 官方未返回有效成绩，本地数据未被覆盖。 |
| 成绩字段校验失败 | 官方成绩字段不完整或无效，本地数据未被覆盖，也未上传查分器。 |
| 同步过程其他异常（含本地保存失败） | 成绩同步失败，未确认上传成功；请检查 HTTPS 网络、依赖和目录权限。 |
| 命令准备阶段其他异常 | 操作失败，请检查本地目录权限后重试。 |

其他连接、授权或服务异常按实际提示处理；必要时获取新凭据、检查网络及插件依赖，或联系管理员。不要反复提交同一凭据，也不要关闭安全校验。

## 7. 取消、重传与删除

「取消成绩更新」回复：

```text
已取消等待 SGID；已开始的同步不会重复执行。
```

实际行为：只取消当前会话的等待，不强行中断已经开始的官方同步。

「重传成绩」使用自己的本地快照，不获取官方数据、不需要新的 SGID；没有额外的开始提示，只发送第4节中的各平台上传/跳过结果行，可能附带曲库跳过提示，不带本地保存的开头及pc50固定尾部。失败分支：

```text
官方成绩同步尚未开启。
你的成绩正在同步，请勿重复提交。
尚无本地成绩，请先「同步成绩」。
本地 PC 数据损坏，请重新同步成绩。
操作失败，请检查本地目录权限后重试。
```

「删除PC数据」成功回复：

```text
已删除本地 PC 和成绩快照，不影响查分器成绩及绑定。
```

同步中删除失败回复：

```text
正在同步成绩，请结束后再删除。
```

## 8. 后续PC查询

「pc50」成功返回现有B50样式的PC50图片，不另发统计文本。失败按情况回复：

```text
尚无本地 PC 数据，请先发送「同步成绩」。
本地没有含有效 PC 次数的普通谱面，请重新同步；缺失次数不会按 0 计算。
本地 PC 数据损坏，请重新同步成绩。
PC50 生成失败，请检查本地数据、字体及图片资源。
```

「我的pc数」是用户主动查询统计，仍保留以下回复，不受本次精简同步通知影响：

```text
已同步谱面 PC 合计：N 次（按谱面计，不是投币次数）。
含 PC 的谱面：N/M；发送「pc50」查看常玩谱面。
```

本文仅展示文案和行为，不包含任何真实 SGID、登录Token、账号ID或玩家数据。

## 9. 冷却及每日次数限制

「官方成绩同步」配置组可独立配置每人取数冷却（默认300秒）、每日取数上限（默认10次）、上传冷却（默认60秒）、每日上传上限（默认20次）。设0关闭对应限制。

同一平台、机器人和发送者跨群、私聊共用额度，持久化保存、重启保留。每日北京时间00:00刷新每日次数，跨日不提前清除冷却。一次处理水鱼和落雪及所有批次合计只扣一次上传次数；上传和重传共用限制。无可上传成绩、均未绑定而未尝试上传时不扣上传次数。

只发起等待、图片识别失败、SGID格式无效、过期或已用不扣取数次数；一旦开始官方请求则失败也计次。开始尝试成绩上传后失败也计次，不按成功结果退还，避免反复失败请求绕过限制。删除PC快照不会清除限流记录。两个对应限制均设0时不记录该操作次数。

正常发起等待时就检查取数额度，被限制则直接回复以下一种，不要求继续发送凭据。直接附带凭据时也会在实际请求前再次检查：

```text
官方取数冷却中，请在 N 秒后重试。
今日官方取数次数已达上限（N 次），请在北京时间次日 00:00 后重试。
```

已取数并保存，但上传受限时，最终消息示例（两种额度提示按实际选择）：

```text
官方成绩已获取并保存到本地。
查分器上传冷却中，请在 N 秒后重试。 本地成绩已保留，可稍后发送「重传成绩」。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

```text
官方成绩已获取并保存到本地。
今日查分器上传次数已达上限（N 次），请在北京时间次日 00:00 后重试。 本地成绩已保留，可稍后发送「重传成绩」。
可发送「pc50」查看常玩谱面；上传失败可发送「重传成绩」。
```

「重传成绩」受限时只发上面对应的额度提示行及“本地成绩已保留……”尾句，不发本地保存开头及pc50固定尾部。

限流配置或存储失败的完整回复如下；发生在上传阶段时另附“本地成绩已保留，可稍后发送「重传成绩」。”，并阻止实际成绩上传：

```text
官方成绩同步限流配置无效，冷却秒数和每日次数必须为非负整数。
成绩同步限流记录无法读取或已损坏，请联系管理员检查；本次未开始新的请求。
成绩同步限流记录保存失败，请联系管理员检查目录权限；本次未开始新的请求。
```

首次成功获取有效成绩后，游戏账号与当前 QQ 建立一对一绑定；后续账号不符或已绑定其他 QQ 时阻止保存和上传。更换账号需管理员在玩家管理中解绑，同步或重传期间不能解绑，解绑后旧快照不能直接重传。该绑定不能核验首次提交凭据的真实归属，请仅使用自己的凭据。
